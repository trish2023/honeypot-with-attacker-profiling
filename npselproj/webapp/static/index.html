OPERATING PRINCIPLE

01 THE HONEYPOT

Two fake services listen on raw TCP sockets — an SSH server (port 2222) and an FTP server (port 2121). They look real (banners, login prompts) but expose no actual system. Anything that connects is an intruder by definition.

02 CAPTURE & ENRICHMENT

Every username / password is logged, then flagged if it matches a known default credential or a top-1000 common password. The source IP is resolved to a country / city via GeoIP.

03 CLASSIFICATION

The time between login attempts betrays the attacker. Sub-500ms gaps mean an automated bot; multi-second gaps mean a human. The engine labels every session live.

04 ADAPTIVE TARPIT

Each failed attempt is answered slower than the last (1s → 3s → 8s → 20s) to waste the attacker's time and slow brute-force tools.

05 THE FAKE SHELL

Some sessions are "granted" access and dropped into a simulated Linux shell. Every command is recorded and tagged by intent — malware download, credential harvesting, recon, persistence — revealing what the attacker wanted.

06 THIS CONSOLE

All of the above streams into SQLite and is pushed here over a WebSocket in real time. The map, charts and feed update as attacks happen.
